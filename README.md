# zerotier_sockets

Join [ZeroTier](https://www.zerotier.com) networks from inside a Dart or Flutter app and talk **TCP and UDP**
over them: no VPN permission, no root, no system service. Bindings for
[libzt](https://github.com/zerotier/libzt) using `dart:ffi` and **native assets**.

Version 2 is a rewrite:

- **Built from source by a build hook** (`hook/build.dart`): libzt 1.8.10 is fetched at a pinned commit and
  compiled with CMake for whatever you build (Android ABIs, Linux, macOS, Windows). No prebuilt `.so` files
  in the repository; Android libraries are 16 KB page aligned (Android 15+). `dart test` works on the desktop.
- **`@Native` bindings** generated by ffigen: no `DynamicLibrary.open`, no loader.
- **UDP** (`ZeroTierDatagramSocket`) and **TCP servers** (`ZeroTierServerSocket`) next to TCP clients.
- One shared, adaptive poll loop for all sockets instead of a timer per socket.

```dart
final node = ZeroTierNode.instance
  ..initStorage('${appDir.path}/zerotier') // keeps the node identity
  ..start()
  ..join(parseNetworkId('8056c2e21c000001')!);
await node.waitUntilReady(networkId: parseNetworkId('8056c2e21c000001'));

final socket = await ZeroTierSocket.connect('10.147.17.5', 22);
socket.stream.listen(print);
socket.add([1, 2, 3]);

final udp = ZeroTierDatagramSocket.bind('0.0.0.0', 0);
udp.listen((packet) => print('${packet.address}:${packet.port} ${packet.data}'));
udp.send([1, 2, 3], '10.147.17.5', 9000);
```

`node.watch()` streams the node's state (online, networks, assigned addresses).

## Building

Needs `git`, CMake and a C/C++ compiler; for Android the NDK (found like Flutter finds it). To build from a
local libzt checkout instead of fetching it, set in your app's `pubspec.yaml`:

```yaml
hooks:
  user_defines:
    zerotier_sockets:
      libzt_src: ../libzt   # a checkout with submodules
```

## Tests

`dart test` runs offline (node identity, binding, errors). Traffic over a real network is opt-in, see
`test/network_test.dart`.
